- 当前状态：M0 已完成，M1 未开始
- 最近更新时间：2026-08-10

## 职责与边界

前端界面负责把认知测试、排行榜、科普文章和项目信息组织成清晰的多页面网站。首页以正式测试为核心，提供快速反应体验和测试入口；练习模式保留独立菜单，不参与正式测试计分或排行榜。

该模块继续使用现有测试组件、成绩提交接口、排行榜接口和博客内容加载，不修改它们的业务规则。站点的技术 SEO 由 [SEO 模块](./SEO.md) 单独归档。

## 结构与数据流

全站由 `Layout` 提供桌面和移动导航、语言切换及页脚。首页通过卡片进入 `/test/[testType]`，并从现有排行榜 API 读取反应测试的前三名、平均成绩和最佳成绩；正式测试完成后沿用原有结果展示和提交逻辑。博客列表和文章详情继续在构建时读取 `content/blog`。

`/practice` 是独立页面。目前用于说明练习与正式测试的边界，并预告反应、记忆和注意力练习；页面不创建练习记录，也不调用成绩提交接口。

## 关键决策

- 继续使用真实页面路由，不采用单页锚点模拟页面切换。
- 网站定位保持为认知测试，练习只作为独立功能入口。
- 正式测试与练习数据分离，练习结果不影响最佳成绩和排行榜。
- 保留中英文导航与关键页面文案。
- 视觉层采用统一 CSS 变量和页面级类名，现有测试组件保持可用。

## 当前实现

- 首页包含产品定位、快速反应体验、九项测试入口和匿名排行榜说明。
- `/test` 支持按反应、记忆、注意力分类筛选，并进入独立测试页。
- `/leaderboard` 保留测试类型切换、统计、加载、失败和空状态。
- `/blog`、`/blog/[slug]` 与 `/about` 已统一到新视觉体系。
- `/practice` 已提供独立导航和边界说明，具体练习功能尚未实现。
- `/practice` 保持 `noindex, follow`，sitemap 只收录可索引的正式测试、文章和信息页。

## 验证方式
